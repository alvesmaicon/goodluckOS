Apps for goodluckOS
===================

Copy an app's .zip file into this folder, then open System Settings > System >
App Installer on the console and install it. The app shows up in the launcher's
Apps tab, or in the tab it asks for (Games).

Each installed app is a folder here. Uninstall it from App Installer (or delete
its folder). Making your own app: see docs/making-apps.md in the goodluckOS
repository.
