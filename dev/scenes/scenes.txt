# dev/gl scenes: one launcher screenshot per line, taken after the keys are pressed.
# Each scene starts Puppy afresh on the games of games.txt, with no favourites or autolaunch.
# Keys are xdotool names; "_" waits 1 s; conf:key=value goes into a puppy.conf for that scene, hud:KEY=value
# into a ~/.config/gallium_hud.conf, set:key=value into Puppy's settings file (set:style=modern), and
# temps:52:78 fakes the CPU's and the power chip's sensors. Puppy's
# keys: F1/F2 = L1/R1, F3 = SELECT, F4 = X (search), F5 = START, F6 = POWER, F7 = L2 + R2, space = Y,
# Return = A, Escape = B.
# Tabs from the boot one (All Games): F2 My List, F2 F2 Terminal...; F1 Genesis, F1 F1 NES.
# Return launches nothing here, but the game goes into Recent, a tab after My List from then on.
# "restart" starts Puppy again on the same files, as after a game; with
# conf:launch_command=/repo/dev/scenes/session.sh each Return is a 75 min session for the play time.
#
